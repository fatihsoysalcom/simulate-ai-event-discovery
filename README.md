# Simulate AI Event Discovery

This example simulates how an AI assistant, like Google Gemini, could process natural language queries to discover events from a database. It uses keyword matching to parse user input and filter a predefined list of events, demonstrating the core concept of AI-powered event discovery described in the article.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`.
Enter queries in Turkish, e.g., 'İstanbul'da bu hafta sonu hangi rock konserleri var?'
